1 照片 → Blender 高精度模型

必拍：正面/背面/左右/頂底/四斜角 + 接口/材質特寫 + 尺/硬幣

你現在要直接操作我的電腦，根據我提供的多張照片，在 Blender 4.4 中重建一個高精度 3D 模型。

目標物件：{{物件名稱}}

工作目標：
根據所有照片，建立一個外觀高度一致、比例正確、可後續編輯與匯出的 PBR 3D 模型，並輸出 Blender 原始檔與 FBX。

執行要求：
1. 先完整檢視所有照片，辨識物件的整體外形、尺寸比例、材質、接口、按鍵、孔位、結構分件與細節。
2. 若照片中有尺度參考物，請用它建立接近真實尺寸的比例；若沒有明確尺度參考，請先依照片估計比例，並在結果紀錄中明確標示「尺寸為估計值，非實測 1:1」。
3. 在 Blender 4.4 中建立乾淨、可編輯的模型：
   - 拓樸盡量規整
   - 物件命名清楚
   - 零件分層合理
   - 原點與座標整理好
4. 盡可能還原以下內容：
   - 整體外觀輪廓
   - 正面 / 背面 / 側面細節
   - 所有可見接口、孔位、按鍵、縫線、凹槽、散熱孔
   - 材質質感（如金屬、塑膠、霧面、亮面、磨砂、沖孔網格）
   - 發光區域、Logo、標示位置
5. 如背面接口可從照片辨識，請建模其外觀；若針腳細節在照片清楚可見，請盡量重建；若看不清楚，不要亂補，請保留合理簡化版本並在紀錄中標示哪些細節無法驗證。
6. 建立基本 PBR 材質：Base Color / Roughness / Metallic / Normal / Emission
7. 建立對照展示場景：中性背景 + 至少 4 個視角渲染圖
8. 輸出：.blend / .fbx / 預覽 PNG / 工作紀錄 markdown
9. 全程直接執行，不要只告訴我做法。

品質標準：外觀一致 / 比例自然 / 材質正確 / 可正常開啟
錯誤處理：不足處標示「推測」/ 看不清不虛構 / 無尺寸標示「非實測 1:1」

2 模型 → 可玩的 3D 小遊戲

Three.js + React / Isometric / WASD + E

使用剛剛完成的 3D 模型，將它改造成一個可在瀏覽器執行的 isometric 互動式 3D 小遊戲。

專案名稱：{{project_slug}}
核心概念：以「{{物件名稱}}」作為地基 / 主體，將它的頂部或主要表面改造成一個可探索的小場景，風格為 {{場景風格}}。

功能需求：
1. Three.js + React 單頁互動作品
2. 保留原本 {{物件名稱}} 的辨識特徵
3. 上方建立：小攤位 / 遮陽棚 / 路燈 / 招牌 / 2-3個 NPC / 可控小角色
4. Isometric 視角，清楚易讀
5. WASD 移動 / 鏡頭跟隨 / 靠近 NPC 按 E
6. NPC：靠近顯示 Press E / 對話框 / 各至少1句台詞
7. 頁面可直接執行 / 載入畫面簡潔 / 標題 / 操作說明
8. 結構：React / Three.js / 模型載入 / 角色控制 / NPC互動 / 樣式
9. 產出：可執行專案 + 單一 HTML (若可行) + README
10. 自行完成安裝開發測試直到可互動

美術：保留辨識度 / 可愛化 / 乾淨 / 色彩統一 {{場景風格}}
品質：一開即見場景 / 可移動 / 2-3 NPC可互動 / 與原模型有關聯 / 無 console error
錯誤：過重自動優化減面 / 材質過重改輕量 / 單一HTML不穩則交付 React
